# Corpus empresarial

Aquí se incorporará el corpus ficticio utilizado en búsqueda semántica y RAG.

La colección final incluirá procedimientos, SLAs, políticas, manuales, FAQs y documentación de servicios, con metadata suficiente para trabajar fuentes, versiones, filtros y documentos obsoletos o relacionados.

Los documentos se añadirán cuando se implemente M05-P02/M06 para poder diseñarlos a la vez que las preguntas de evaluación y evitar un corpus artificialmente fácil.
