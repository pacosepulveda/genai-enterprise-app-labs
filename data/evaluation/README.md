# Dataset de evaluación

Las preguntas de evaluación se diseñarán junto al corpus de conocimiento para medir retrieval y respuestas de RAG de forma coherente.

Se almacenarán casos con, al menos:

- pregunta;
- fuente o fuentes esperadas;
- hechos esperados;
- casos sin evidencia;
- casos deliberadamente ambiguos o con documentos relacionados.
